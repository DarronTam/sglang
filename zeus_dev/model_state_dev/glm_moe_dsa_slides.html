Sparse Attention 只看 TopK token

toy shape: 1 head, D=2, Dv=2。query t=3 的 top2 = [3,2]

张量值
q[3][1, 0]
k[3][2, 0]
k[2][1, 1]
v[3][4, 1]
v[2][1, 3]
scale = 1/sqrt(2) = 0.707
score3 = dot([1,0],[2,0]) · 0.707 = 1.414
score2 = dot([1,0],[1,1]) · 0.707 = 0.707
softmax([1.414,0.707]) ≈ [0.67,0.33]
out = 0.67·[4,1] + 0.33·[1,3] = [3.01,1.66]
Dense causal attention 会看 0..3；DSA sparse attention 只看 top-k 的 [3,2]。 当 topk ≥ 当前有效长度时，sparse 结果应与 dense causal 完全一致。

DSA 的核心不是一个 attention kernel，而是一条 cache-aware 流水线

1. Projection

q_a/q_b
kv_a/kv_b
RoPE split/concat

2. Indexer

wq_b/wk
weights_proj
score + topk

3. Cache

index K cache
main K/V cache
paged slots

4. Sparse MLA

topk indices
softmax over selected tokens
o_proj
