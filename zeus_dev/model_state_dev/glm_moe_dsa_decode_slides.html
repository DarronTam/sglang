7 / 11

从 main K/V cache 做 sparse attention

selected_k = main_k_cache[physical_topk_slots] → [Ktop,32,192]
selected_v = main_v_cache[physical_topk_slots] → [Ktop,32,128]
score[h,k] = dot(Q[b,h,:], selected_k[k,h,:]) / sqrt(192)
prob = softmax(score over Ktop)
out[b,h,:] = Σ_k prob[h,k] · selected_v[k,h,:] → [32,128]
这一步对应 SGLang 的 FlashMLA / TRT-LLM DSA decode 路径；对 Zeus 来说，它是最重要的 cache-aware sparse attention kernel。

Decode path 的 kernel 优先级

P0: indexer logits/topk

q_idx × index K cache
head gate 加权
top-k local indices

P0: sparse attention

topk slot gather
QK softmax
AV output

P1: cache store

index K cache
main K/V cache
slot untouched invariant
Decode path 的性能核心是 “少读 cache + 少 materialize logits”。优先把 top-k 与 cache sparse attention 跑通，再考虑 FP8 index cache / IndexCache。
