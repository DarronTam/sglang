一层 decode 的组装顺序（MHCLayerCommunicator）

residual_in [T, N=4, H] │ attn_hc.pre ──▶ layer_input [T,H] ▼ self_attn(layer_input) ┌─ layer ∈ full_attn → DSA decode │ └─ else → Linear-attn decode │ attn_hc.post ──▶ residual_mid [T, N·H] ▼ │ mlp_hc.pre ──▶ layer_input [T,H] ▼ mlp(layer_input) ┌─ dense layer → SwiGLU(clamp) │ └─ else → MoE │ mlp_hc.post ──▶ residual_out [T, N·H] ▼ residual_out ──▶ 下一层
关键：sublayer 永远只看 单流 [T,H]； 多流 mixing 全在 mHC pre/post 完成 ⇒ 换 attention 类型 不影响 mHC wrap（完全解耦）。
KDA sublayer

Linear-attention (KDA) decode sublayer

layer_input [B,H]
├─ qkv_proj → mixed_qkv [B, 3·proj] (q|k|v 融合)
├─ b_proj → beta / f_b(f_a) → forget_gate / g_b(g_a) → g_proj
↓ decode
conv1d_update(mixed_qkv)+silu → q,k,v (单步 per-channel conv)
g_gate = −exp(A_log)·softplus(forget_gate+dt_bias) ; beta=sigmoid(beta)
↓ 单步 delta-rule（S 先 decay 再 readout）
q̂=l2norm(q)·scale ; k̂=l2norm(k)
S = S·exp(g_gate) ; v̂=k̂·S ; S += beta·(v−v̂)⊗k̂ ; o = q̂·S
↓
o = rms_norm_gated(o, g_proj, sigmoid) ; out = o_proj(o.flatten()) [B,H]
16B: 32 heads × 72 Next: 64 heads × 128 conv state + recurrent state 原位推进

kernel 级对拍见 dev_kimi_linear_attn_test.py::kimi_delta_attn_decode

DSA decode sublayer（复用 dsa 模块 REF）

layer_input [B,H] ┌─ #0 q_a/kv_a proj + RMSNorm → q_lora, latent_kv[slot] ├─ #1 q_main（MLA absorb, Dro=0） → q_new [B,Nh,Rkv] ├─ #2 Indexer Q/K（Hadamard + fp8） → q_body, k_body, weights ├─ #3 index logits（GEMM→gate→scale） ├─ #4 local topK（≤Ktop） ├─ #7 latent gather（owner filter） ├─ #8 sparse MQA partial（FA-v2） └─ #10 V absorb + o_proj → out [B,H]
本脚本把 mHC 的 layer_input 作为 DSA 的 hidden 喂入，cp=1 no-CP decode，输出 [B,H] 交回 attn_hc.post。 详见 glm5next_dsa_decode_dev.md。
mHC wrap
8 / 10

mHC：把单流 sublayer 包成多流残差

attn_hc.preresidual[T,N,H] → layer_input[T,H] (暂存 h_res, h_post)
self_attn单流 [T,H] KDA / DSA decode → attn_out[T,H]
attn_hc.postscatter 回 N 流 → residual_mid [T, N·H]
mlp_hc.preresidual_mid → layer_input[T,H] (暂存 h_res, h_post)
mlp单流 [T,H] SwiGLU / MoE → mlp_out[T,H]
mlp_hc.postscatter 回 N 流 → residual_out [T, N·H] · fp32 accum + 单次 bf16 RNE · comb 是 doubly-stochastic 混合矩阵 ⇒ N 条流不再恒等
每层 2 个 HyperConnection（attn-side / mlp-side），权重独立。 mHC 内部 5 步（norm_fn / split / sinkhorn / apply / post）见 glm5next_mhc_dev.md + glm5next_mhc_slides.html。
