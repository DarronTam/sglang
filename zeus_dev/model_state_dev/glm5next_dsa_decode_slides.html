#0 / #2 显式拆分：两个独立 kernel，不 fuse

hidden_state [B,H] │ ├─ #0.Q dsa_q_a_proj_norm │ hidden → q_a_proj → RMSNorm → q_lora [B,Rq] │ ├─ #0.KV dsa_kv_a_proj_norm_store │ hidden → kv_a_proj → RMSNorm → latent_kv_cache[slot, :] │ ↑ in-place scatter │ ├─ #2.K dsa_indexer_k_prep_store │ hidden → wk → 完整 LayerNorm(γ, β) → Hadamard / √Di │ → fp8 e4m3 quant → cache_body[slot] / cache_scale[slot] │ └─ #2.Q dsa_indexer_q_weights (消费 q_lora，不直接消费 hidden 做 K 路径) q_lora → wq_b → reshape [B,I,Di] → Hadamard / √Di → fp8 e4m3 hidden → weights_proj → gate → weights = gate · I^-½ · q_scale · Di^-½
#0 / #2 都显式不 fuse：#0.Q 和 #0.KV 独立 grid=(1,)，hidden 各读一次； #2.Q 与 #2.K 互不依赖（输入只有 q_lora / hidden / slot_mapping），首版 dev 分 stage 对齐， fuse 决策留给 porting 阶段。
#1 q-main 与 #2.Q 都消费 q_lora，但计算性质不同（#1 是 heavy GEMM + absorb bmm，#2.Q 是 indexer prep）。

7 / 12

Index logits：GEMM → gate → scale

q_idx_fp8: [B, I=8, Di=128]
index_K_local: [B, S_local, Di=128]
raw = q_idx_fp8 · index_K_local^T # [B,I,S_local]
logits = sum_i(raw_i · weights_i) # [B,S_local]
logits = logits · k_scale # scale 只乘 [B,S_local]
为什么 scale 放最后
避免对 [B,I,S_local] 做 broadcast 乘法； scale 是 per token row，一个 [B,S_local] 乘法即可。
CP 之前基本无感
CP 只改变 S_local 与 global position offset； all-gather local topK 前 kernel 主体不变。

TopK：本地 select，CP>1 再 merge

logits_local [B,S_local] │ ├─ if S_local ≤ 2048: │ return all valid positions + padding(-1 / -inf) │ └─ else: radix select → local_topk(logit,pos) [B,2048] CP=1: global_topk = local_topk CP>1: all-gather local_topk across CP ranks merge-topK over CP × 2048 candidates → global_topk_pos [B,2048]
Local radix select 与 global merge-topK 是同类问题；后者输入已经是候选集， 但要保留 tie-break 规则，保证 CP=1 与 CP>1 可对齐。

Sparse MQA：partial 接口固定输出 out + lse

q_new: [B,Nh,512] # from #1 absorb
K_local: [B,Ktop,512] bf16 # from #7, invalid 行 garbage
mask: [B,Ktop] bf16 (1.0 / 0.0) # from #7, score · mask + (1−mask)·-1e9
partial_out: [B,Nh,512] # FA-v2 在线 softmax
partial_lse: [B,Nh]
CP=1
partial_out 就是全局 latent attention 输出；post kernel 只做 V absorb + o_proj。
CP>1
all-gather (partial_out, partial_lse)， 再做 FA-reduce + V absorb + o_proj。
FA-reduce
10 / 12

FA-reduce：不能用 all_reduce(sum) 替代

partial_out_r [B,Nh,512], partial_lse_r [B,Nh]

m = max_r(partial_lse_r)
z = Σ_r exp(partial_lse_r - m)
out_latent = Σ_r exp(partial_lse_r - m) · partial_out_r / z

attn_out = bmm(out_latent.T, w_vc[Nh,512,Dv]).T
out = o_proj(attn_out.reshape(B, Nh·Dv))
空集 rank 约定：partial_lse=-inf，merge 权重为 0。 裸 all_reduce(sum) 会丢掉 softmax 分母信息，数学不等价。

11 / 12

CP page/block interleave 与 2-core Index Lmem

DSA cache follows page attention. CP owner is decided by page/block group, not by one contiguous sequence chunk. Example: CP=4, two core Index Lmem are treated as two adjacent blocks block pair 0 → rank0 / core0, rank0 / core1 block pair 1 → rank1 / core0, rank1 / core1 block pair 2 → rank2 / core0, rank2 / core1 block pair 3 → rank3 / core0, rank3 / core1 block pair 4 → rank0 / core0, rank0 / core1 ...
对 #3/#4 Index logits/topK 来说，只需要知道本 rank 的 S_local 和每行的 global position；是否 CP、CP 几路，在 local-topK all-gather 之前都不改变核心逻辑。
