7 / 11

Ragged indexer logits + TopK

for each flat query row q: req = token_to_request[q] valid key slots = prefix slots(req) + current chunk slots(req, <= q_pos) q_idx[q] [8,128] Kidx_valid [S_q,128] weights[q] [8] score[q,s] = Σ_i weights[q,i] · dot(q_idx[q,i], Kidx_valid[s]) topk_indices[q] = topk(score[q,:], min(index_topk, S_q))
如果 S_q <= index_topk，可以跳过 sparse top-k 的收益路径，直接 dense/MHA one-shot。这对应 SGLang 的 dense fallback 阈值策略。

Prefill sparse attention

for each query row q:
selected_slots = local_to_physical_slots(req, topk_indices[q])
selected_k = main_k_cache[selected_slots] → [Ktop,32,192]
selected_v = main_v_cache[selected_slots] → [Ktop,32,128]
out[q,h,:] = softmax(Q[q,h] · selected_k[:,h] / sqrt(192)) · selected_v[:,h]

Prefill path 的 kernel 优先级

P0: cache store/fetch

batch write out_cache_loc
paged fetch valid slots
untouched slot invariant

P0: ragged topk

per-row valid key span
no cross-request leakage
topk padding -1

P1: sparse prefill

selected slot gather
QK softmax AV
backend threshold
Prefill path 不是 decode kernel 的简单批量版：它需要 ragged metadata、请求隔离、prefix+current chunk 的可见性，以及短上下文 dense fallback。
