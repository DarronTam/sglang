一个 HyperConnection 的 pre / post 往返

(K1) mhc_pre_norm_split ★融合 #1+#2BLOCK_T 1-pass：RMSNorm(flatten N·H, fp32) + F.linear(fn fp32) → mixes[T,24] → x·scale+base → sigmoid → split: pre[T,4,1] / post[T,4,1] / comb[T,4,4] （mixes 不落 DRAM）
(K2) sinkhorncomb logits → doubly-stochastic repeat = 20
(K3) apply_mix(residual×pre).sum(stream) → layer_input [T,H] bf16
SUBLAYER单流 [T,H] attn: DSA / Linear-attn mlp : MoE / dense
(K4) mhc_postout[t,n,h] = post·x_sub + Σ_m comb[t,m,n]·residual[t,m,h] （fp32 accum → 单次 bf16 RNE） → residual_out [T, N·H] bf16
pre_forward = (K1)→(K2)→(K3)，返回 layer_input + 暂存 h_res(comb) / h_post(post)； post_forward = (5)，把 sublayer 单流输出 scatter 回 N 条流。

K1 双核并行：device 2-core 推荐 split-K 12/12

为什么不切 T，切 K？
fn[24, N·H] fp32 ≈ 0.75 MB (16B) / 1.5 MB (Next)，每层静态、每次调用读一次。
residual[T, N·H] bf16 ≈ 16 KB·T (16B) / 32 KB·T (Next)。
decode 单步 T 小（常 ≤ 16），fn 主导 DRAM 带宽。切 K → 每核 fn 流量减半；切 T → 两核都拉全 fn，浪费一半。
# 临界 T ≈ 48；T ≥ 48 时（prefill）才反转为切 T 更优。
12 / 12 是唯一均衡分法
切法GEMM 行平衡
12 / 12 ★12 / 121 : 1
8 / 16 (pre+post / comb)8 / 161 : 2
4 / 20 (pre / 其它)4 / 201 : 5
post-process 异构（core0 含 sigmoid，core1 全 elementwise），但 GEMM 主导 → 不平衡 < 5%。
core 0 ── 12 行 GEMM (dims 0..11) ───────── 异构 post-process ── 写 disjoint ─
  load residual[t,:]
  rsqrt = rsqrt(mean(x²)+eps) # ← 与 core1 冗余
  mixes_local[0..11] = fn[0..11,:] · x · rsqrt
    dims 0..3 → pre (σ + eps) → write pre[t,:]
    dims 4..7 → post (σ · 2) → write post[t,:]
    dims 8..11 → comb row 0 (scale+base) → write comb_logits[t,0,:]

core 1 ── 12 行 GEMM (dims 12..23) ──────── 同构 post-process ── 写 disjoint ─
  load residual[t,:]
  rsqrt = rsqrt(mean(x²)+eps) # ← 与 core0 冗余
  mixes_local[12..23] = fn[12..23,:] · x · rsqrt
    dims 12..23 → comb rows 1..3 (scale+base 同构)
     → write comb_logits[t,1:4,:]
fn 流量减半 · 输出写盘 disjoint rsqrt 两核冗余算 ≈ +4% reduce / 0 barrier BLOCK_T 内循环不变 · tile-invariance 保留 T ≥ ~48 (prefill) 才切 T

Sinkhorn-Knopp：投影到 Birkhoff polytope

# 首轮特殊：softmax 而非 exp，且只做列归一
x = comb.softmax(-1) + eps
x = x / (x.sum(-2, keepdim=True) + eps) # 列归一

# 之后 (repeat-1) 轮交替 行 → 列
for _ in range(repeat - 1):
  x = x / (x.sum(-1, keepdim=True) + eps) # 行归一
  x = x / (x.sum(-2, keepdim=True) + eps) # 列归一

# 共 2·repeat − 1 次 reduce（不是 2·repeat！）
不变量：收敛后 comb[t] 是 doubly-stochastic —— 行和≈1、列和≈1、全非负。
迭代数敏感：20 iter 下 |row_sum−1|≈1e-6；10 iter 下≈1e-3。config 走谁用谁。
