absorb matrix

kv_b_proj 离线拆 w_kc / w_vc

// deepseek_weight_loader.py:565-610（权重加载阶段）
w = kv_b_proj.weight # shape [Nh*(Dnope+Dv), Rkv] = [8192, 512]
w_kc, w_vc = w.unflatten(0, (-1, Dnope+Dv)).split([Dnope, Dv], dim=1)

w_kc: [Nh=32, Rkv=512, Dnope=128] # K 吸收
w_vc: [Nh=32, Rkv=512, Dv=128] # V 解吸收
Prefill absorb 分支：每 token 走 bmm(q_nope, w_kc) + sparse → bmm(out_latent, w_vc)。
Prefill fallback 分支：直接调 kv_b_proj 把 latent 解开成 32 头 K/V，跑标准 FlashAttention，不 用 w_kc/w_vc。
absorb 数学

Prefill 四步流（默认分支）

[Step 1] P1 — Q 侧 K 吸收
  q_nope = Q[..., :Dnope] # [T, 32, 128]
  q_nope_out = bmm(q_nope.T, w_kc).T # [T, 32, Rkv=512]

[Step 2] P4 — latent 空间 sparse MQA（ragged）
  q = concat(q_nope_out, q_pe) # [T, 32, 576]
  indices = topk_slots # [T, Ktop=2048] (causal-aware)
  attn_out_latent = flash_mla_sparse_fwd(...) # [T, 32, Rkv=512] ★

[Step 3] P5 — V 解吸收
  attn_out = bmm(attn_out_latent.T, w_vc).T # [T, 32, Dv=128]

[Step 4] P6 — o_proj
  out = o_proj(attn_out.reshape(T, Nh*Dv)) # [T, H=2048]

P4-alt 详解

Dense fallback：什么时候、做什么

触发条件

max_kv_len ≤ 2048 (= index_topk)
AND not is_blackwell
AND backend.use_mha == True
短序列下 dense 比 sparse + 吸收快——sparse 的 topk + index cache IO 开销不划算。

做什么

1. 用 kv_b_proj 解 latent
   → K [T, 32, Dnope+Dro=192]
   → V [T, 32, Dv=128]
2. FlashAttention varlen
   kv = prefix(cache) + current
3. 输出 attn_out [T, 32, 128]
4. 跳过 P5 V absorb，直进 P6
Zeus 端：absorb 分支与 fallback 分支必须分别实现并按阈值切换；REF 测试用例要覆盖两种情况—— `prefill_full_path` 跑长序列走 absorb，`dense_fallback_policy` 单测一份短序列对照。

总结

Prefill V3 一句话

Prefill 默认与 decode 共用 absorb 路径，只是
sparse 调用换成 flash_mla_sparse_fwd，top-k 改 ragged，cache 批量写；
短序列（max_kv_len ≤ 2048）才切 MHA_ONE_SHOT 走 dense 解 KV。
Indexer 别忘了 Hadamard；可见区按 prefix + causal 当前 chunk 来。
