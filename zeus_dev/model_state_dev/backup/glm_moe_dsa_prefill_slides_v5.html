// deepseek_common/attention_backend_handler.py::handle_attention_nsa if hasattr(backend, "use_mha") and backend.use_mha: return AttnForwardMethod.MHA_ONE_SHOT return AttnForwardMethod.MLA // ★ 默认：absorb（与 decode 共用 forward_absorb_prepare/core，sparse 换 ragged 版） // nsa_backend.py::set_nsa_prefill_impl → 计算 use_mha（普通 extend；decode/verify 始终 False） self.use_mha = ( (device_sm in {90} or 100 <= device_sm < 110) // Hopper / Blackwell 一类 and max_kv_len <= SGLANG_NSA_PREFILL_DENSE_ATTN_KV_LEN_THRESHOLD // 默认 = index_topk = 2048 and kv_cache.dtype in {bfloat16, fp8_e4m3} and sum_seq_lens <= forward_batch.get_max_chunk_capacity() and not is_nsa_enable_prefill_cp() and hisparse_coordinator is None ) // server_args._handle_model_specific_adjustments(): DSA architecture 未手动设 threshold 时默认 = index_topk

// Glm5NextForCausalLM.load_weights → post_load_weights（deepseek_weight_loader.py:565-585）

Prefill 五步流（默认 absorb 分支；main MLA 全程无 RoPE）

[Step 0] P1 — qkv_a layernorm + split (latent 来自 communicator)
  q_lora = q_a_layernorm(q_lora_raw) [T,768] # 也是 indexer 输入

[Step 4] P6 — o_proj

短序列两条路

"短序列"在 prefill 里有两个不同的分支

① absorb 路径内：K-only 快捷路径（_forward_cuda_k_only）

触发：max_kv_len ≤ index_topk = 2048 且非 CP
做什么：
  · indexer 只算 K（含 RoPE/Hadamard/FP8），写 index cache
  · 跳过 q / weights / logits
  · topk_transform(dummy_logits) → [0,1,...,len-1, -1, ...]
  · 即"全选可见 token" → sparse 退化为 dense，但仍走 absorb（P4 + P5）
attention dispatch 仍是 AttnForwardMethod.MLA；只是 topk 不真的算。

② attention dispatch 层：MHA_ONE_SHOT（P4-alt）

触发：set_nsa_prefill_impl 判 use_mha=True —— 需同时
  · SM90 或 100 ≤ SM < 110（Hopper/Blackwell）
  · max_kv_len ≤ threshold（默认 2048）
  · kv_cache.dtype ∈ {bf16, fp8_e4m3}
  · sum_seq_lens ≤ max_chunk_capacity · 非 CP · 无 hisparse
做什么：kv_b_proj 解 latent → 32 头 K/V → FlashAttention varlen
  输出 [T,32,Dv=128]，不用 w_kc/w_vc，跳过 V 吸收
indexer 仍跑（return_indices=False）只为把 index K cache 填上，供后续层/decode 用。
Zeus：absorb 主路径（含 K-only 快捷路径）先做；MHA_ONE_SHOT 作独立策略后补。REF 用例 prefill_full_path 跑长序列走 absorb，dense_fallback_policy 单测一份短序列对照（模拟硬件条件）。

总结

Prefill V5 一句话

Prefill 默认与 decode 共用 absorb 路径，只是 sparse 调用换 ragged 版、topk 改 ragged（causal）、cache 批量写；
主 MLA 路径 mla_nope=True ⇒ 全程不做 RoPE（只 indexer 前 64 维 NeoX）；
q_a_layernorm → q_b_proj → split → bmm w_kc 投到 latent，sparse 输出 [T,32,Rkv=512]，bmm w_vc 解到 Dv=128，o_proj 回 H；
短序列两条路：absorb 内 K-only 快捷路径（topk 全选可见，仍走 absorb）；以及 SM90/Blackwell 上的 MHA_ONE_SHOT（解 kv_b_proj 跑 dense varlen，不吸收）。
indexer K 用完整 LayerNorm + Hadamard；w_kc [32,128,512] / w_vc [32,512,128]；architecture 名不用改；CP/跨层 topk 复用是后续项。
