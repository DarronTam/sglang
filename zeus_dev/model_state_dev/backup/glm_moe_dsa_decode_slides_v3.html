Decode 视角的三个修正

问题V1 写法（错）V3 写法
D4 sparse attention Q [B,32,Dv=128] 直接吃 main K/V，按 32 KV 头算 DSA decode 默认走 MLA absorb；latent KV 头 = 1，输出 [B,Nh,Rkv=512]

Decode path 现在是 7 步 D0–D6，相比 V1 多出 D0 fused qkv-a 拆分 与 D5 v-absorb。

attention dispatch

Decode 在 NSA backend 下 — 强制 absorb

// attention_backend_handler.py::handle_attention_nsa def handle_attention_nsa(attn, forward_batch): backend = forward_batch.attn_backend if hasattr(backend, "use_mha") and backend.use_mha: return AttnForwardMethod.MHA_ONE_SHOT // ★ 只 prefill 才会触发 return AttnForwardMethod.MLA // ★ decode 永远走这条：absorb // 同 deepseek_v2.py::dispatch_attn_forward_method attn_forward_method == MLA → forward_absorb_prepare(...) // 含 bmm(q_nope, w_kc)、indexer topk → forward_absorb_core(...) // 含 attn_mqa、bmm(out, w_vc)、o_proj
结论：DSA decode 没有"dense 短路"分支，永远走 absorb。 这与 vanilla MLA 的 prefill 走 chunked-KV/MHA 解开是不同的概念。
absorb matrix

kv_b_proj 离线拆 w_kc / w_vc

// deepseek_weight_loader.py:565-610（权重加载阶段）
w = kv_b_proj.weight # shape [Nh*(Dnope+Dv), Rkv] = [8192, 512]
w_kc, w_vc = w.unflatten(0, (-1, Dnope+Dv)).split([Dnope, Dv], dim=1)

w_kc: [Nh=32, Rkv=512, Dnope=128] # K 吸收
w_vc: [Nh=32, Rkv=512, Dv=128] # V 解吸收
Decode 时 不调 kv_b_proj 做 decompress。 Q 侧用 w_kc 把 q_nope 投到 K 的列空间；attention 输出后用 w_vc 解吸收回真实 V dim。 main KV cache 只存 [B, 1, Rkv+Dro=576] 的 latent，省 KV cache 显存与 IO。
absorb 数学

Decode 四步流

[Step 1] D1 — Q 侧 K 吸收
  q_nope = Q[..., :Dnope] # [B, 32, 128]
  q_nope_out = bmm(q_nope.T, w_kc).T # [B, 32, Rkv=512]

[Step 2] D4 — latent 空间 sparse MQA
  q = concat(q_nope_out, q_pe) # [B, 32, 576]
  kv = main_kv_cache[topk_slots] # [B, Ktop=2048, 1, 576]
  attn_out_latent = flash_mla_with_kvcache(...) # [B, 32, Rkv=512] ★

[Step 3] D5 — V 解吸收
  attn_out = bmm(attn_out_latent.T, w_vc).T # [B, 32, Dv=128]

[Step 4] D6 — o_proj
  out = o_proj(attn_out.reshape(B, Nh*Dv)) # [B, H=2048]

总结

Decode V3 一句话

Decode 路径强制走 MLA absorb；
sparse attention 发生在 [B, Nh, Rkv+Dro=576] 潜空间，输出 [B, Nh, Rkv=512]；
用离线拆好的 w_kc / w_vc 完成 K 吸收 / V 解吸收，最后 o_proj 回 H。
Indexer 别忘了 Hadamard；RoPE 别共用 main 与 indexer。
