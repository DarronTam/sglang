"head 数" 澄清

四种 head，运行时各管各的

名称config 字段值 运行时角色cache layout
Q 头 (Nh)num_attention_heads32 q_b_proj 输出 reshape [*,32,Dqk=192]；absorb 后 [*,32,Rkv=512] —
GQA KV 头num_key_value_heads8 MLA 路径不用；只在 Glm4MoeAttention（非 MLA）下当作 GQA KV 头数 —
潜空间 KV 头 (h_kv)—1 absorb fast path 真正落 cache 的头数；RadixAttention(num_kv_heads=1, v_head_dim=Rkv=512) [pages, 64, 1, Rkv+Dro=576]
decompress 视角num_attention_heads32 仅 MHA_ONE_SHOT dense fallback；kv_b_proj 解 latent 得 32 头 借用 absorb cache
Indexer 头 (I)index_n_heads8 q_idx [*,8,128]；k_idx [*,128]（单 head 共享） [pages, 64, 1, Di=128] + scale
"GQA KV 头 = 8" 与 "Indexer 头 = 8" 数值相同是巧合，没有任何映射关系。 "32 个 KV 头" 只在 dense fallback 才会出现，不是 DSA decode/prefill 的常态。

absorb matrix

kv_b_proj 离线拆 w_kc / w_vc

// deepseek_weight_loader.py:565-610
w = kv_b_proj.weight # shape [Nh*(Dnope+Dv), Rkv] = [8192, 512]
w_kc, w_vc = w.unflatten(0, (-1, Dnope+Dv)).split([Dnope, Dv], dim=1)

w_kc: [Nh=32, Rkv=512, Dnope=128] # K 吸收
w_vc: [Nh=32, Rkv=512, Dv=128] # V 解吸收
含义：把 kv_b_proj（rank=512 → 32 头 K + 32 头 V）这两部分**离线**拆开。 运行时不再调 kv_b_proj 做 decompress，而是把 K 吸收进 Q，把 V 在 attention 输出后解吸收。 cache 只存 [*, 1, Rkv+Dro] latent，省 KV cache 显存与 IO。
absorb 数学

四步流：D1/P1 → D4/P4 → D5/P5 → D6/P6

[Step 1] Q 侧 K 吸收
  q_nope = Q[..., :Dnope] # [T, Nh, 128]
  q_nope_out = bmm(q_nope.T, w_kc).T # [T, Nh, Rkv=512]

[Step 2] 潜空间 sparse MQA
  q = concat(q_nope_out, q_pe) # [T, Nh, Rkv+Dro=576]
  kv = main_kv_cache[topk_slots] # [T, Ktop, 1, 576]
  attn_out_latent = sparse_mqa(q, kv) # [T, Nh, Rkv=512] ★

[Step 3] V 解吸收
  attn_out = bmm(attn_out_latent.T, w_vc).T # [T, Nh, Dv=128]

[Step 4] o_proj
  out = o_proj(attn_out.reshape(T, Nh*Dv)) # [T, H=2048]
decode/prefill 共用同一对函数：forward_absorb_prepare + forward_absorb_core (models/deepseek_common/attention_forward_methods/forward_mla.py)

总结

V3 一句话

DSA decode 与 prefill 都默认走 MLA absorb；
sparse attention 发生在 [*, Nh, Rkv+Dro=576] 潜空间，输出 [*, Nh, Rkv=512]；
用离线拆好的 w_kc / w_vc 完成 K 吸收 / V 解吸收，最后 o_proj 回 H。
Indexer 别忘了 Hadamard；RoPE 别共用 main 与 indexer。
prerelease 有 GlmMoeDsaForCausalLM 脚手架 tests: zai-org/GLM-5-FP8 已跑通 本地 config 需做架构名映射
