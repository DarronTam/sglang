decoder layer 流程

fused_qkv_a_proj_with_mqa 在 layer communicator 里跑

// Glm5NextDecoderLayer.forward() —— DSA 层 (layer_id ∈ [3,7,11,15,19,23]) hidden_states, residual │ ├─ layer_communicator.prepare_attn(...) // MHCLayerCommunicator (config.mhc=True) │ - input_layernorm / scatter / MHC 残差流处理 │ - qkv_latent_func = self_attn.prepare_qkv_latent │ → qkv_latent = fused_qkv_a_proj_with_mqa(hidden) // [B, 1344] │ → 写入 get_attn_tp_context() │ ├─ self_attn.forward(...) // DSA 子层正文 (D1 起) │ - q_lora_raw, latent_cache = fetch_qkv_latent() // split [768] / [576] │ - dispatch_attn_forward_method() → handle_attention_nsa() │ - DSA full-attn 默认 AttnForwardMethod.MLA (absorb) │ - forward_absorb_prepare / forward_absorb_core │ ├─ layer_communicator.prepare_mlp(...) → mlp(...) // MoE / dense FFN，不在本切片 └─ layer_communicator.postprocess_layer(...)
所以 D0 = dsa_pre_attn_qkv_latent（communicator 内）；forward_absorb_prepare 起手就是 q_lora_raw [B,Rq] + latent_cache [B,Rkv+Dro]。 Zeus 首版按非-MHC 普通 LayerCommunicator 语义对齐即可，MHC 残差作外层包装单独处理。

Decode 在 NSA backend 下 — 强制 absorb

// deepseek_common/attention_backend_handler.py::handle_attention_nsa def handle_attention_nsa(attn, forward_batch): backend = forward_batch.attn_backend // NativeSparseAttnBackend if hasattr(backend, "use_mha") and backend.use_mha: return AttnForwardMethod.MHA_ONE_SHOT // 只 prefill 可能触发；decode 始终 use_mha=False return AttnForwardMethod.MLA // ★ decode 永远走这条：absorb // deepseek_v2.py::dispatch_attn_forward_method → 选定 MLA 后 → forward_absorb_prepare(...) // q_a/kv_a layernorm · q_b_proj · split · bmm(q_nope,w_kc) · indexer→topk → forward_absorb_core(...) // attn_mqa(..., topk_indices=...) · bmm(out,w_vc) · o_proj
DSA decode 没有"dense 短路"分支，永远走 absorb。 index_topk_freq=1、index_topk_pattern=None（默认）⇒ 每层各自算 topk，不跨层复用。
absorb matrix

kv_b_proj 离线拆 w_kc / w_vc（权重加载阶段）

// Glm5NextForCausalLM.load_weights → DeepseekV2WeightLoaderMixin.post_load_weights
// deepseek_common/deepseek_weight_loader.py:565-585
w = kv_b_proj.weight # shape [Nh*(Dnope+Dv), Rkv] = [8192, 512]
w_kc, w_vc = w.unflatten(0, (-1, Dnope+Dv)).split([Dnope=128, Dv=128], dim=1)
# w_kc 此时 [Nh,Dnope,Rkv] = [32,128,512]；w_vc [Nh,Dv,Rkv] = [32,128,512]
self_attn.w_kc = w_kc.transpose(1,2).contiguous().transpose(1,2) # 仍是 [32,128,512]，仅改内存布局
self_attn.w_vc = w_vc.contiguous().transpose(1,2) # → [Nh,Rkv,Dv] = [32,512,128]
Decode 时 不调 kv_b_proj 做 decompress。Q 侧用 w_kc 把 q_nope 投到 latent K 列空间；attention 输出后用 w_vc 解吸收回真实 V dim。 main latent KV cache 只存 [B, 1, Rkv+Dro=576]，省显存与 IO。
absorb 数学

Decode 五步流（main MLA 全程无 RoPE）

[Step 0] D1 — qkv_a layernorm + split (latent 来自 communicator)
  q_lora = q_a_layernorm(q_lora_raw) # [B, 768] ← 也是 indexer 的输入
  k_nope = kv_a_layernorm(latent_cache[..., :Rkv]).unsqueeze(1) # [B, 1, 512] ★只 norm 前 512
  k_pe = latent_cache[..., Rkv:].unsqueeze(1) # [B, 1, 64] 未 norm、未 RoPE

[Step 1] D2 — q_b_proj + split + K 吸收
  q = q_b_proj(q_lora).view(B,32,192) → q_nope[B,32,128], q_pe[B,32,64] # q_pe 未 RoPE
  q_nope_out = bmm(q_nope.T[Nh,B,Dnope], w_kc[Nh,Dnope,Rkv]).T # [B, 32, Rkv=512]

[Step 2] D4 — latent 空间 sparse MQA
  q = concat(q_nope_out, q_pe) [B,32,576] ; k = concat(k_nope,k_pe) [B,1,576]
  attn_out_latent = attn_mqa(q, k, k_nope, fb, topk_indices=topk_slots) # [B, 32, Rkv=512] ★
  # save_kv_cache=True → 内部把 [1,576] 写主 latent KV cache[out_cache_loc]

[Step 3] D5 — V 解吸收
  attn_out = bmm(attn_out_latent.T[Nh,B,Rkv], w_vc[Nh,Rkv,Dv]).T # [B, 32, Dv=128]

[Step 4] D6 — o_proj
  out = o_proj(attn_out.reshape(B, Nh*Dv=4096)) # [B, H=2048]

总结

Decode V5 一句话

Decode 强制走 MLA absorb； 主 MLA 路径 mla_nope=True ⇒ 完全不做 RoPE（只 indexer 前 64 维 NeoX）。
第一个 GEMM fused_qkv_a_proj_with_mqa 在 layer communicator 里跑；
q_a_layernorm → q_b_proj → split → bmm w_kc 投到 latent；
sparse attention 在 [B,32,Rkv+Dro=576] 潜空间，输出 [B,32,Rkv=512]；
bmm w_vc 解吸收回 Dv=128，最后 o_proj 回 H=2048。
indexer K 用完整 LayerNorm + Hadamard；w_kc [32,128,512] / w_vc [32,512,128]；architecture 名不用改。
